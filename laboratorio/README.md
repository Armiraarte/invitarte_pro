# INViTARTE Laboratorio

Proyecto independiente del constructor dinámico de invitaciones de INViTARTE.

## Qué incluye

- Panel principal del laboratorio
- Constructor visual por secciones
- Historial local de diseños
- Generación de mensaje con Gemini
- Vista previa móvil/tablet/desktop

## Ejecutarlo localmente

1. Entra a `laboratorio/`
2. Instala dependencias con `npm install`
3. Crea un archivo `.env.local`
4. Agrega `GEMINI_API_KEY=tu_api_key`
5. Ejecuta `npm run dev`

## Build

- `npm run build`
- `npm run preview`

## Nota

Esta carpeta está preparada para subirse como proyecto aparte y apuntarse a otro dominio sin depender del landing principal.
