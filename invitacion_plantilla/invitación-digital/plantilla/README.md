# Proyecto independiente de invitacion

Este proyecto se genera para que puedas editar la invitacion fuera del panel principal.

## Ejecutarlo en local

```powershell
npm install
npm run dev
```

Despues abre `http://localhost:3000`.

## Compilarlo

```powershell
npm run build
npm run preview
```

## Importante

- No abras `index.html` con doble clic para editar la invitacion.
- Si recibiste este proyecto en ZIP, primero extraelo completo.
- Si vas a usar accesos personalizados, RSVP o datos del evento por API, tambien necesitas el backend PHP del proyecto principal en `127.0.0.1:8000`.
